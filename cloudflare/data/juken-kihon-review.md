# 市高データ（英単語・古文・歴史）と「基本・応用」の見直し

`data/juken-fixes.json`（市高の3教科）と `data/kihon-fixes.json`（HAMACHI の「基本・応用」kbn=1）に入れた変更の一覧。どちらもまだ適用していない提案。

## ファイルの形

### juken-fixes.json

キーは `<教科>:<番号>` 形式。
- **rekishi:<no>** … `no` は1〜179で重複がないので番号だけ。
- **kobun:<no>:<ko>** … 145（ありし／ありつる）と178（ごかう／ぎやうがう／ぎやうけい）は同じ番号に複数語があるので、見出し語 `ko` まで付ける（全件同じ形にそろえた）。
- **eigo:<no>:<en>** … 英単語は関連語（rel）が見出し語と同じ番号を持つので `no` だけでは決まらない。`en` 単独も leave／judge など8語が重複する。`no:en` の組は全3634語で重複なし。

フィールド：
- 歴史：`q` 問題文、`a` 答えの表記、`kana` 打つ読み、`alts` ほかに正解にする読み（かな）。データの `alt` は表示用の別表記で、打つ読みには使われていなかったので、正解にしてよいものは `alts` に読みを入れた。
- 古文：STEP1 は意味（`ja`）を見て古語（`ko`）を打ち、STEP2 は例文訳の空欄の意味（`kana`）を打つ。`alts` は STEP2（`kana`）の別解、`koAlts` は STEP1（古語）の別解、`q` は STEP1 の問題文（`ja`）の差し替え。
- 英単語：STEP1 は意味（`ja`）を見て英語（`en`）を英字で打ち、STEP2 は例文訳の空欄の意味（`kana`）を打つ。`enAlts` は STEP1 の別のつづり、`alts` は STEP2（`kana`）の別解。

### kihon-fixes.json

キーは problems の `id`。`que`／`kan` は差し替え後の全文、`ans` は「|」区切りで先頭が表示する読み。

件数（変える語・問題の数）：英単語 180 語、古文 82 語、歴史 43 問、基本・応用 66 問（英単語は be なし・英つづり・同じ問題文・STEP2 が重なる語があるので、下の各節の件数の合計とは合わない）

# 見送ったもの

- **英字だけの略語の答え（sram、dram、sla、ldap、saml、swot など約90問）**：かな読み（えすらむ、える だっぷ 等）は足していない。先行の IT 系の見直しでも DRAM・SRAM・WBS などの英字だけの答えにはかな読みを足しておらず、それに合わせた。足すなら、文字読み（えすえるえー）と単語読み（えるだっぷ）のどちらを入れるか方針を決める必要がある。
- **英単語 STEP2 のほかの訳語を全部正解にすること**：例 prepare の「用意する」に対する「準備する」など。3634語すべてで、訳語のうち例文の空欄に合う言い方を拾う必要があり、多義語（press：押す／報道機関）では文脈に合わない訳語を入れてしまうおそれがある。今回は「答えが訳語に無い」ものだけにした。広げるかはご判断ください。
- **英単語 STEP1 の「ほぼ同じ意味」の語（decline／refuse の「断る」など）**：問題文（ja）が完全に一致するものだけ直した。訳語が少しでも違うもの、語感メモ（nu）や関連語の説明（df）で区別できるものはそのまま。
- **英つづり tyre（tire）、storey（story）、cheque（check）**：イギリス式は「タイヤ」「階」「小切手」の意味のときだけ。見出しの主な意味（疲れさせる／物語／確かめる）では使わないので足していない。
- **英単語 STEP2 で答えが訳語より短いもの（絶対的な→【絶対】的な、全国的な→【全国】など）**：例文の空欄の外に「的な」が書いてあり、打つ長さも ○ で見えているのでそのまま。
- **古文 145 ありし の意味**：一般には ありし＝「以前の・生前の」、ありつる＝「さっきの」。本が同じ番号・同じ訳でまとめているので、訳語は変えずに両方を正解にするだけにした。
