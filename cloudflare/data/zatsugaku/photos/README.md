# 写真の雑学の一覧

列：キー | 答え | 読み（空ならカタカナから） | 別の答え（,区切り） | Wikipedia の記事名（空なら答え） | レベル（1〜5） | ひとこと（解いたあとに出す） | 国（世界遺産だけ） | Commons のファイル名（写真を選び直すときだけ）

写真は `node scripts/fetch-photos.mjs` が、記事の Wikidata の「画像」（P18、Wikimedia Commons）から取ってくる。
作者とライセンスは `<一覧>.credits.json` に残り、解いたあとの解説に出る。
写真が答えと合わないときは、最後の列に Commons のファイル名を書いて取り直す。
