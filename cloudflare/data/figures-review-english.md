## 絵のスタイル（統一ルール）

- 200×200 の viewBox、背景は透明（場面によっては空や部屋の色の四角を敷いています）。
- 線はすべて濃い紫がかったグレー（#3a3440）・太さ4px・角丸。塗りはフラットな単色（赤 #e8574f・オレンジ #f59e42・黄 #f7ce46・緑 #6cc070・青 #4a90d9・水色・ピンク・茶・グレー・肌色）。
- 人物は同じ形の「丸い頭＋角丸の胴体＋太い手足」のキャラクターで統一。
- **体の部位**：体全体をうすいグレーで描き、答えの部位だけをオレンジ（口・ほおは赤）で塗って赤い矢印で指しています。
- **比べる形容詞**（big / small / tall / short / ripe など）：答えのほうを色つき、比べる相手をうすく（半透明）描いています。
- 動詞は「その動作をしている人」の小さな場面、天気・自然は風景として描いています。
- 眠っている様子は「Zzz」の文字の代わりに、泡と三日月のマークで表しています。
- 同じセット内で別の単語に同じ絵は使っていません（koko-eigo と english-buzzer の間では同じ絵を共用しているものがあります）。
